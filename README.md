# ML Engineering Journey

My 6+ month journey from mobile/software engineering into ML engineering, with a focus on GenAI and LLMs.

Following a personal study plan (see `plan/` for details).

## Structure
- `notebooks/` — Jupyter notebooks for exercises and experiments
- `projects/` — Standalone projects (Month 1 capstone, etc.)
- `notes/` — Written notes on concepts, papers, blog posts

## Stack
- Python 3.12, managed with [uv](https://github.com/astral-sh/uv)
- PyTorch (CUDA via NVIDIA RTX 500 Ada on HP ZBook)
- WSL2 Ubuntu 24.04 on Windows 11
